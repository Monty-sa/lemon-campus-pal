# Security policy

Please report suspected vulnerabilities privately to the developer on Telegram: https://t.me/Muntadar26.

Include the affected area, impact, safe reproduction details, and the version or commit tested. Do not send credentials, access tokens, real student records, destructive payloads, or publicly disclose an unresolved vulnerability.

You should receive an acknowledgment before any coordinated public disclosure. General support and feature requests should use the repository's normal issue process after the public repository is available.
